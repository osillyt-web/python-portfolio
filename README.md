# Портфолио Python — Alex (фриланс: боты, парсинг, автоматизация)

Здесь собраны мои рабочие программы на Python: код + настоящий вывод работы.

## Что внутри

| Программа | Что делает | Что показывает |
| --- | --- | --- |
| `programs/bot_echo.py` | Telegram-бот: отвечает на сообщения | aiogram, команды, работа с ботом в облаке |
| `programs/bot_knopki.py` | Telegram-бот с кнопками | кнопки, обработка нажатий |
| `programs/dnevnik.py` | Заметки: добавить, показать, удалить | меню, файлы, чтение/запись, обработка ввода |
| `programs/kurs_valyuts.py` | Берёт курс валют с сайта банка | запрос к API, разбор JSON |

## Настоящий вывод программ (не картинка — реальный запуск)

**Курсы валют (живой запрос к Национальному банку Украины):**

```
$ python kurs_valyuts.py
Курс фунта: 60.9233
```

**Дневник заметок (полный цикл: добавил → показал → удалил → вышел):**

```
$ python dnevnik.py
--- Дневник заметок ---
1. Добавить заметку
2. Показать все
3. Удалить заметку
4. Выход
Что делаем? 1
Твоя заметка: Купить фильтр для бензокосы
Заметка сохранена!
...
Что делаем? 2
1. Купить фильтр для бензокосы
2. Позвонить клиенту по заказу
...
```

Полные расшифровки запусков — в папке `outputs/`.

**Telegram-бот:** запускается и слушает Telegram — доказательство в `outputs/bot_echo_out.txt`
(ответ Telegram «already running» на второй запрос с тем же токеном).

## Навыки

Python · файлы и текст · JSON и запросы к API · Telegram-боты (aiogram: кнопки, команды, состояния) ·

## Как запускать

```bash
python programs/kurs_valyuts.py
python programs/dnevnik.py
python programs/bot_echo.py     # нужен свой токен бота от @BotFather
```

Токены в репозиторий не выкладываются.
